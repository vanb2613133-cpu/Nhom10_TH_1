# Nhom10_TH_1 - Bài Thực Hành

## Mô tả nội dung
Repository này lưu trữ và quản lý các bài tập, sản phẩm thực hành của **Nhóm 10**. Nội dung bao gồm các tệp nguồn, tài liệu và báo cáo thực hành liên quan.

## Trích dẫn nguồn AI
Trong quá trình hoàn thành bài thực hành, nhóm có sử dụng hỗ trợ từ các công cụ AI sau:
- **Google Bard (Gemini)**: Hỗ trợ tra cứu thông tin, tổng hợp ý tưởng và tối ưu mã nguồn.
- **Canva AI**: Hỗ trợ thiết kế hình ảnh, đồ họa và trình bày tài liệu/slide.
